# 大元素使 · 万象归一

在 Godot 打开 `elementalist.tscn` 按 F6，或运行项目后在画廊选择 Elementalist。
1 / 空格重播，2 慢放，R 重置，Q 切换魔法画质，Esc 返回画廊。
默认「炸裂」画质；电脑吃力时用 Q 切到「极致」或「均衡」。

这是一段约 29 秒的演示，时间轴使用动作时间；顿帧会增加实际播放时长。
「大元素使」逐字砸字、口播、音乐和音效留给后续剪辑。

| 动作时间 | 画面 |
|---|---|
| 0–3s | 五元素徽记汇入施法者背后的法阵，镜头推近后拉回 |
| 3–6.25s | 16 颗火球沿螺旋轨迹升空，悬停成花冠 |
| 6.25–7.9s | 冰晶从花冠直线落下，保留在地面 |
| 7.9–10s | 金沙细丝连接冰晶，目标周围出现密集沙丝 |
| 10–12.2s | 多个普通雷电起终点首尾串联，引爆悬停的火球和冰晶 |
| 12.2–18.05s | 风的龙卷携带火、冰、雷、沙四种材质，持续扩大 |
| 18.05–20.1s | 风暴缩小，五种材质沿轨迹回到手边 |
| 20.1–23.4s | 镜头推近，小球蓄力、吸入五元素粒子，再拉回发射 |
| 23.4–27.4s | 火环、冰柱、雷网、五元素环与最终爆开依次收尾 |

全部招式使用通用 `cast` / `camera` / `hit` 事件，未添加按演示名称判断的代码。
形状与材质独立：`shape` 选择彗星、光束、环、柱、漩涡、法阵；`element` 和 `mix`
决定材质。已有元素的招牌形状保持原实现；冰仍遵循直线运动规则。
坐标端点与端点列表、`linger`、`burst`、`swell` 也能在手动精调里编辑。

运行检查：

```text
godot --headless --path . res://combos/elementalist/elementalist.tscn -- --verify
godot --headless --path . --script res://tools/verify_magic_composition.gd
```
